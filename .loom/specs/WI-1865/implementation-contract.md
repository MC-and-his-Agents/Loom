# WI-1865 Implementation Contract

## Scope

- Release authority: `VERSION`, `package.json`, `plugins/loom/.codex-plugin/plugin.json`.
- Release evidence: `docs/evidence/v0.26.0-release-readiness.md`.
- Loom carriers: `.loom/work-items/WI-1865.md`, `.loom/progress/WI-1865.md`, `.loom/status/current.md`, `.loom/specs/WI-1865/*`, `.loom/reviews/WI-1865*.json`, and closeout/merge-ready shadow evidence.

## Required Behavior

- Root `VERSION` must be `v0.26.0`.
- Root `package.json` version must be `0.26.0`.
- Plugin payload metadata must carry `source_package_version` and `plugin_payload_version` of `0.26.0`.
- Plugin payload hash must be generated by `tools/stamp_plugin_payload_metadata.py`.
- Release PR metadata must declare `change_class=release`, `suite_path=minimal`, and `release_judgment=release_required`.
- Release PR checks must remain read-only for publication.
- Post-merge closeout must wait for release readback to prove tag, GitHub Release, npm package, workflow, and package surface consistency.

## Non-Goals

- No new runtime behavior after #1859.
- No multi-repo batching.
- No plugin surface version bump.
- No host adapter or skills contract version bump.
- No legacy installer release.
- No manual overwrite of tag, GitHub Release, or npm package.
