# Spec Suite Template

本文件承接 Loom 当前对正式规约模板的落点。

## 当前核心落点

### `EXT-0015`

`spec.md` 应至少表达：

- 目标
- 范围
- GWT 场景
- 异常与边界
- 验收标准

### `EXT-0016`

`plan.md` 应至少表达：

- 实施目标
- 阶段拆分
- 约束
- 验证
- TDD
- 依赖关系
- 进入实现前条件

## 当前候选落点

### `EXT-0017`

正式套件需要最小集，但“最小集包含哪些文件”不应被过早固化成永恒规则。

当前结论：

- Loom 必须区分正式契约工件和执行/进度工件
- `TODO.md` 之类工件不应先验写死成所有项目的正式最小套件
