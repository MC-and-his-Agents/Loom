# Status Surface

本文件定义 Loom 当前最小状态面合同。

## 1. 状态面服务读取，不服务并行记账

状态面的目标是让人和智能体快速读取当前执行状态，而不是制造第二套真相源。

## 2. 最小输出

Loom 当前至少要求状态面能展示：

- 当前事项
- 当前执行路径
- 当前 checkpoint 阶段
- 当前工作现场
- 当前恢复入口
- 当前阻断项
- 下一步
- 最近验证摘要

## 3. 派生优先

状态面应尽量从已有真相源派生，而不是手工维护一份平行状态。

默认要求：

- 能引用 issue、PR、checkpoint、恢复工件等现有载体
- 不与正式规则或执行工件并行维护相同字段

## 4. Loom 当前约束

Loom 需要状态面能力，但当前不固化：

- 展示媒介
- UI 形态
- 具体脚本实现

Loom 当前只固化它的最小输出语义与“不得成为第二真相源”的边界。
