# Status Surface

本文件定义 Loom 当前最小状态面合同。

本文件当前承接：

- `EXT-0035`

## 1. 能力定位

状态面用于快速读取当前执行状态和运行事实。

它服务读取，不服务并行记账。
它既包括文档状态，也包括最小运行时可见性。

## 2. 最小状态输出

Loom 当前至少要求状态面能展示：

- 当前事项
- 当前执行路径
- 当前 checkpoint 阶段
- 当前工作现场
- 当前恢复主入口
- 当前阻断项
- 下一步
- 最近验证摘要

## 3. 运行时可见性

若事项涉及可运行系统，状态面还应提供可读取的运行时事实入口。

最小目标包括：

- 当前工作现场对应的运行入口
- 日志或等价运行输出可见
- 指标、trace 或等价诊断信息至少有一种可见
- UI、接口或端到端结果存在 agent 可验证入口

Loom 固化的是“可读取、可验证”的能力目标，不固化具体可观测工具栈。

## 4. 派生与边界

状态面应尽量从已有真相源派生，例如：

- work item
- checkpoint / 恢复工件
- issue / PR
- 验证记录
- 运行输出

禁止事项：

- 手工维护第二套平行真相
- 在状态面重复承接正式规则定义
