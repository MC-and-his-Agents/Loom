# Execution Context

本文件定义 Loom 当前最小执行上下文合同。

本文件当前承接：

- `EXT-0011`

## 1. 执行上下文必须显式绑定

进入执行的事项，不得只靠单一编号或口头约定识别。

默认要求：

- 正式执行前，必须绑定一组稳定上下文字段
- checkpoint、resume、handoff、review 应共享同一上下文基线
- 上下文必须能支持恢复，而不是只支持“当下看懂”

## 2. 最小字段集合

Loom 当前至少要求执行上下文能回答：

- 当前事项是谁
- 当前事项属于哪类执行路径
- 当前目标是什么
- 当前工作现场是什么
- 当前主恢复入口是什么
- 当前处于哪个 checkpoint 阶段

## 3. 字段命名保持参数化

Loom 固化字段语义，不固化下游仓库的具体字段名。

默认要求：

- 可以按项目需要映射成不同命名
- 但不得删掉最小语义集合

## 4. Loom 当前约束

Loom 需要保留“执行上下文绑定”能力，但当前不直接固化：

- 具体字段名
- 具体工具字段来源
- 具体平台编号格式
