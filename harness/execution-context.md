# Execution Context

本文件定义 Loom 当前最小执行上下文合同。

本文件当前承接：

- `EXT-0011`
- `EXT-0038` 的每轮读取部分

## 1. 能力定位

执行上下文用于把单次执行轮次绑定到同一组稳定事实。

它服务：

- 开始执行前的读取
- checkpoint 与 resume 的对齐
- handoff 与 review 的事实对齐

它不负责保存恢复内容本身；恢复内容由 `recovery-model.md` 承接。

## 2. 最小语义集合

每次正式执行前，至少要能确定以下语义：

- 当前事项是谁
- 当前事项属于哪条执行路径
- 当前目标是什么
- 当前工作现场是什么
- 当前恢复主入口是什么
- 当前 checkpoint 阶段是什么

Loom 固化的是语义集合，不固化字段名、编号格式或平台来源。

## 3. 每轮读取要求

进入正式执行轮次前，默认先读取：

- 当前 work item 或等价执行入口
- 当前恢复主入口中的 progress / checkpoint
- 当前工作现场对应的最近 git 历史

读取完成后，本轮执行应只声明一个清晰推进单元，不在同一轮并行吞入多个无关目标。

## 4. 边界约束

- 不得只靠 issue 编号、分支名或聊天上下文识别当前事项
- 不得让执行、恢复、review 分别使用不同的上下文基线
- 若某字段只是下游仓库局部便利，不得提升为 Loom 固定字段
