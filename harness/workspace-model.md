# Workspace Model

本文件定义 Loom 当前最小工作现场模型。

本文件当前承接：

- `EXT-0025`
- `EXT-0012`

## 1. 隔离执行现场

正式执行链路默认使用隔离工作现场。

默认要求：

- 同一时间的正式事项，应有独立执行现场
- 执行现场必须能明确映射到单一事项
- 正式链路不得默认复用脏现场推进新事项

## 2. 单现场单事项

工作现场的默认职责是单现场单事项。

禁止事项：

- 在同一现场并行推进多个正式事项
- 在同一分支或同一 PR 中混入多个无关目标

## 3. 现场标识可确定性恢复

Loom 需要保留确定性现场机制，但不固化下游仓库的命名格式。

默认要求：

- 现场标识应能由稳定输入生成
- 同一事项的恢复动作，应能推导回对应现场
- 命名规则可以参数化，但不得完全依赖人工约定

## 4. Loom 当前约束

Loom 当前只固化以下规则：

- 正式链路默认使用隔离现场
- 单现场单事项
- 现场标识应可确定性恢复

Loom 当前不固化：

- 具体目录命名格式
- 具体 worktree 命令细节
