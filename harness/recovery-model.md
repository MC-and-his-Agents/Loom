# Recovery Model

本文件定义 Loom 当前最小恢复模型。

本文件当前承接：

- `EXT-0003`
- `EXT-0013`

## 1. 恢复能力必须入库

长任务不得只依赖聊天记录、分支名或操作者记忆恢复。

默认要求：

- 长任务必须存在持久化恢复工件
- 恢复工件必须支持 `checkpoint`、`resume`、`handoff`
- 恢复工件必须与当前事项直接绑定

## 2. 唯一恢复主入口

每个长任务必须有唯一恢复主入口。

默认要求：

- 任何继续执行动作，都应先回到该主入口
- 其他辅助工件只能补充，不得成为并行主入口

禁止事项：

- 在多个文档中并行维护“下一步”
- 让 reviewer 或接手者自行猜测哪份记录更新

## 3. 最小恢复事实集

恢复主入口至少应能回答：

- 当前事项是什么
- 当前停点在哪里
- 下一步是什么
- 已验证了什么
- 仍阻断什么

## 4. Loom 当前约束

Loom 的最小 harness 至少必须提供：

- 可写入的 `checkpoint`
- 可读取的 `resume` 主入口
- 可交接的 `handoff` 信息
- 单一事项的唯一恢复主入口
