# Automation Frontload

本文件定义 Loom 当前最小自动化前置规则。

本文件当前承接：

- `EXT-0009`

## 1. 可自动判断的规则应前置

能稳定自动判断的规则，不应长期停留在人工 review 中。

默认要求：

- 口径稳定的规则优先脚本化
- 高频重复判断优先脚本化
- 可结构化判断的规则优先脚本化

## 2. 前置范围

适合前置到脚本或 CI 的规则，至少包括以下类型：

- 命名或结构完整性
- 必填工件存在性
- 基础状态一致性
- 纯度或范围越界的明显信号

## 3. 不应错误前置

以下判断不应被伪装成可完全自动化：

- 方案是否正确
- 风险是否真正收口
- 当前实现是否解决了正确问题

## 4. Loom 当前约束

Loom 的 harness 必须把“适合自动判断的规则”与“需要语义判断的规则”分开。

不允许：

- 把可自动判断事项长期留给人工重复执行
- 把语义判断错误地下沉成硬编码脚本
