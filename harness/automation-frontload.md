# Automation Frontload

本文件定义 Loom 当前最小自动化前置规则。

本文件当前承接：

- `EXT-0009`
- `EXT-0036`

## 1. 能力定位

能稳定机械判断的规则，应尽量前置到脚本、CI 或等价自动化入口。

自动化前置负责降低重复人工判断，不负责替代语义审查。

## 2. 最小前置范围

适合前置的检查，至少包括：

- 命名、目录与结构完整性
- 必填工件存在性
- 基础状态一致性
- 纯度或明显越界信号
- 知识结构完整性
- 关键交叉链接可达性
- 模板存在性与必要字段完整性
- 执行支撑入口存在性

这里的“执行支撑”包括初始化入口、恢复入口、验证入口或其他被正式规则要求的机械支撑。

## 3. 不应错误前置的判断

以下判断不应被伪装成全自动结论：

- 目标是否值得做
- 方案是否正确
- 风险是否真正收口
- 当前实现是否解决了正确问题

## 4. 边界约束

Loom 的自动化前置必须区分两类事情：

- 机械判断交给机器
- 语义判断保留给人、reviewer 或其他正式治理角色

不允许：

- 把可自动判断事项长期留给人工重复执行
- 把需要语义判断的事项伪装成硬编码脚本结果
