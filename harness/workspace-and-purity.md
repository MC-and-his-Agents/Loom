# Workspace And Purity

本文件定义 Loom 当前最小纯度规则。

本文件当前承接：

- `EXT-0029`

## 1. 纯度应前置校验

分支职责纯度和 PR 范围纯度，不应只在 review 阶段才第一次暴露。

默认要求：

- 执行前或提交前，应有纯度预检
- 纯度问题应尽量在进入正式 review 前暴露

## 2. 最小纯度目标

Loom 当前至少要求以下纯度：

- 分支目标纯度
  - 一个正式分支服务一个主要事项
- PR 范围纯度
  - 一个 PR 只承载同一语义目标下的改动
- 工作现场职责纯度
  - 当前现场不混入无关事项的执行残留

## 3. 纯度异常的默认处理

发现纯度异常时，默认动作应是：

- 停止继续叠加改动
- 先拆分、清理或重新分流
- 再进入后续审查

## 4. Loom 当前约束

Loom 必须把纯度机制落到 harness，而不是只写成协作倡议。
