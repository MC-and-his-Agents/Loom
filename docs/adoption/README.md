# Adoption

`adoption/` 负责回答两个问题：

1. 为什么需要 Loom。
2. 一个项目如何采用 Loom，以及当前已识别能力应落到哪里。

术语约束：

- 正式术语统一使用 `repo companion`
- 历史材料中的 `companion docs` 仅作迁移/回溯表述
