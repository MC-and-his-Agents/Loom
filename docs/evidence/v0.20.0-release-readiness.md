## Consumed Behavior

- `loom ship` is the default daily delivery command after a PR exists.
- The wrapper emits short diagnostics by default and reserves detailed output
  for `--json` / `--full-output` surfaces.
- Safe metadata/carrier/shadow repair runs before merge checks when inputs are
  explicit and non-conflicting.
- Generated-only and carrier-only drift do not receive the same friction as
  semantic source drift.
- Changed paths select the smallest useful validation profile.
- Ordinary light / standard work can finish through inline / host-only closeout,
  while release, versioned terminal evidence, reinforced governance, and parent
  or milestone closeout still upgrade to an explicit closeout path.
