# v0.13.0 CLI Release Readiness

This file records the #1009 release candidate for the first `loom` CLI release
published by the main-push `loom-cli-release` workflow.

## Version Decision

The next root `VERSION` is `v0.13.0`.

`v0.12.0` already has a GitHub `v*` tag and GitHub Release. #1009 needs an
unpublished `VERSION` candidate so that the #1008 main-push publish path can
create the new CLI tag and release without overwriting prior release history.

## Release Scope

This release candidate consumes the #1003 migration sequence through #1008:

- #1005 disabled active `loom-installer` publishing.
- #1006 moved user-facing release guidance to the `loom` CLI line.
- #1007 enforced that installer state is legacy evidence only.
- #1008 enabled `loom-cli-release` to publish automatically after eligible
  `main` merges.

The release ships the CLI-first release authority and generated skill package
version surfaces for `v0.13.0`.

## Expected Publish Evidence

After the #1009 PR merges to `main`, closeout must record:

- the #1009 merge commit SHA,
- a new `v0.13.0` git tag pointing at that merge commit,
- a GitHub Release for `v0.13.0`,
- the successful `loom-cli-release` workflow run for that merge commit,
- `@mc-and-his-agents/loom-installer` npm `latest` unchanged from `0.1.119`,
- no new `loom-installer-v*` tag or GitHub Release created by #1009.

## Non-Goals

This release does not add a new npm package, Homebrew formula, standalone
binary, installer publish path, or repo-specific profile rewrite.
