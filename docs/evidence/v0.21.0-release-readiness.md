  release occupancy, main head, and carrier active/terminal facts into a short
  blocked/fixed/next_action diagnostic.

  carrier, review record, and shadow state so closeout facts do not remain split
  between host truth and repo carrier truth.
- `loom release readback` / `loom release resume` combine tag, GitHub Release,
  npm version/dist-tag, release workflow, package surface, and carrier state into
  `published`, `missing`, `drifted`, or `blocked`.

  shipped path when they directly affect closeout consistency.
