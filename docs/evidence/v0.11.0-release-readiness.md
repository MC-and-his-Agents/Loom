This file records the release readiness basis for Loom `v0.11.0`.

It preserves the `orchestration-core` / `orchestration-extension` /
`orchestration-live` split. Hooks are intentionally an optional extension
profile; they do not become a default core gate.

## Frozen Hook Boundary

The release freezes these hook boundaries:

- hook locators are repo-relative declarations, not executable scripts owned by
  Loom core
- mapped hook envelopes use `context_injection`, `blocking_decision`, and
  `runtime_evidence`
- hook safety invariants cover path containment, truth pollution, host trust,
  permission risk, cleanup scope, and unsafe adapter results
- `orchestration-extension/hooks` uses `loom-hooks-extension-profile/v1`
- missing hooks are `not_applicable`; optional/advisory hook gaps stay
  profile-local; required unsafe hooks block only the configured extension path

## Release Judgment

`v0.11.0` can be tagged and released when:

- the root repository `VERSION` is `v0.11.0`
- all #534 FR and Work Item issues are closed as completed, not deferred
- `main` is clean and contains the four merged batch commits above
- final local validation passes on the release candidate
- GitHub tag/release `v0.11.0` points to the validated release commit
