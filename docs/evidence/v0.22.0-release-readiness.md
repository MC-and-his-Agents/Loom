Merging the release PR to `main` is publish-capable because this branch changes
`VERSION`, root `package.json`, plugin payload release metadata/hash, and release
readiness evidence. The expected publish mechanism is the existing
`loom-cli-release` workflow triggered by push to `main`.

The workflow must still fail closed if the version is already occupied, package
metadata does not match `VERSION`, `NPM_TOKEN` is unavailable, runtime parity
fails, or release evidence becomes partial.
