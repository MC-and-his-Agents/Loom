## Governance Mode

Default mode remains `host-enforced`. `advisory/local-enforced` is a low-assurance fallback that requires explicit opt-in and must not be counted as strong governance maturity. High-risk `release`, `security`, `payment`, and `data_migration` changes require separate explicit approval before advisory fallback can pass.
