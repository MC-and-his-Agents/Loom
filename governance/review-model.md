# Review Model

本文件定义 Loom 当前最小审查模型。

这些规则来自当前已标记为 `core` 的提取条目：

- `EXT-0004`
- `EXT-0014`
- `EXT-0018`

## 1. 审查职责分层

Loom 默认把审查拆成三层：

- 语义审查
  - 判断事项或实现是否在解决正确问题
- 自动检查
  - 判断结构、测试、脚本和基础门禁是否通过
- 合并前门禁
  - 判断当前 head 是否满足进入主干的实际条件

禁止事项：

- 用 CI 替代语义审查
- 用 merge gate 替代方案/实现判断
- 让最终合并门禁承担全部前序审查职责

## 2. 最小必要上下文

审查输入默认采用最小必要上下文。

默认要求：

- 只提供当前事项、当前改动、当前风险所需材料
- 只有在当前证据不足时，才补充更多历史材料

禁止事项：

- 默认把整仓历史塞给 reviewer
- 让 reviewer 先做二次侦察，后做判断

## 3. 审查必须有基线

最小必要上下文不等于没有基线。

Loom 当前要求：

- 每次审查都必须有明确对照基线
- 该基线必须足以回答“是否在解决正确问题”
- 但基线必须尽量短，并与当前事项直接相关

## 4. Loom 当前结论

Loom 的 review 体系必须同时满足：

- 有明确职责分层
- 有最小必要上下文
- 有可复核的对照基线
- 不把 merge 前 review 变成第一次理解整个事项
