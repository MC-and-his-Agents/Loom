# Output Contract

使用本文件约束 `loom-init` 的输出。

## 必须输出的区块

### 1. 项目判断

简要说明：

- 当前是新项目还是既有仓库
- 当前最主要的结构性问题是什么
- 为什么推荐这组 Loom 能力

### 2. 推荐装配

至少列出：

- 现在要引入的能力
- 这些能力分别来自 `governance`、`harness`、`templates`、`adoption` 的哪些规则

### 3. 暂不引入

必须显式写出：

- 当前不引入哪些 Loom 能力
- 不引入的原因是什么

### 4. 首批工件

至少说明：

- 需要创建或更新哪些文件
- 每个文件承担什么职责

### 5. 首批事项

至少拆出：

- 第一步要做什么
- 下一步要做什么
- 哪些事项需要 checkpoint 后再继续

### 6. 验证与收口

至少说明：

- 如何判断初始化结果可用
- 哪些状态或证据到位后可以视为本轮 adoption 收口
